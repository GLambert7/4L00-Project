*** FISH N' GUPPIES WHITEBOX v2.0 ***

Instructions to play:
1. Extract files from Whitebox.zip
2. Open Whitebox folder
3. Open 4L00 Project.exe file
4. Press the start button
5. Instructions for puzzles can be read by talking to in game companions

Controls (Keyboard // Gamepad):
- Look = Mouse // Right stick
- Move = WASD // Left stick
- Pause = Tab // Start

- Rise = Space //  Right trigger
- Sink = Shift // Left trigger
- Dash = Control // Left stick press

- Talk with companions = Q // Button east
- Interact using Dolphin = E // Button north
- Interact using Octopus = R // Button west
- Interact using Eel = T // Button south
- Cancel companion standby = C // N/A
